Connect XLR8.ai to Claude, Cursor, Claude Code, VS Code, Codex, or another AI assistant. Paste the server URL and sign in with the same account you use at [app.tryxlr8.ai](https://app.tryxlr8.ai). There is nothing to install.

The server URL is `https://mcp.tryxlr8.ai/mcp`.

<Note>
  Opening this URL in a browser does not load a page. Paste it into your AI client.
</Note>

<Columns cols={2}>
  <Card title="Sign in" icon="key-round">
    Paste the URL and approve access in the browser. Use this on your own computer.
  </Card>

  <Card title="API key" icon="rectangle-ellipsis" href="/mcp/connect#use-an-api-key">
    For a client that cannot open a browser. Use the key issued for your XLR8.ai account.

## Connect your client

### Cursor

Cursor connects from its MCP settings. You can also follow the [Cursor MCP documentation](https://cursor.com/docs/mcp).

<Steps>
  <Step title="Add the server">
    Open **Settings → MCP** and add a server, or create `.cursor/mcp.json` in the project (or `~/.cursor/mcp.json` for every project):

    ```json
    {
      "mcpServers": {
        "xlr8": {
          "url": "https://mcp.tryxlr8.ai/mcp"
        }
      }
    }
    ```
  </Step>
  <Step title="Sign in">
    Cursor opens a browser. Sign in with your XLR8.ai account.
  </Step>
</Steps>

### Claude

In Claude on the web, desktop, or mobile, open **Settings → Connectors → Add custom connector**.

<Steps>
  <Step title="Name the connector">
    Use `XLR8`.
  </Step>
  <Step title="Paste the server URL">
    Use `https://mcp.tryxlr8.ai/mcp`.
  </Step>
  <Step title="Sign in">
    Claude opens a browser so you can sign in with your XLR8.ai account. The connector stays off until that sign-in finishes.
  </Step>
</Steps>

### Claude Code

Install [Claude Code](https://code.claude.com/docs/en/setup) first. Details are in the [Claude Code MCP documentation](https://docs.anthropic.com/en/docs/claude-code/mcp).

<Steps>
  <Step title="Add the server">
    ```bash
    claude mcp add --transport http xlr8 https://mcp.tryxlr8.ai/mcp
    ```
  </Step>
  <Step title="Sign in">
    In Claude Code, run `/mcp` and finish sign-in in the browser.
  </Step>
</Steps>

`claude mcp list` shows whether XLR8.ai is connected.

### VS Code

Create `.vscode/mcp.json` in the project. See the [VS Code MCP documentation](https://code.visualstudio.com/docs/agent-customization/mcp-servers).

```json
{
  "servers": {
    "xlr8": {
      "type": "http",
      "url": "https://mcp.tryxlr8.ai/mcp"
    }
  }
}
```

VS Code asks you to start the server, then opens a browser so you can sign in.

### Codex

Install the [Codex CLI](https://developers.openai.com/codex/cli) first. See the [Codex MCP documentation](https://developers.openai.com/codex/mcp/).

<Steps>
  <Step title="Add the server">
    ```bash
    codex mcp add xlr8 --url https://mcp.tryxlr8.ai/mcp
    ```
  </Step>
  <Step title="Sign in">
    ```bash
    codex mcp login xlr8
    ```

    Finish sign-in in the browser.
  </Step>
</Steps>

### Another client

Paste `https://mcp.tryxlr8.ai/mcp` into the client's custom server field and sign in when the browser opens. If it asks for a transport, choose HTTP.

If the client can only run a program on your computer, use this configuration. It opens a browser so you can sign in.

```json
{
  "mcpServers": {
    "xlr8": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.tryxlr8.ai/mcp"]
    }
  }
}
```

## Use an API key

Use an API key when the client cannot open a browser, including when you are connecting an agent.

The key is issued for your XLR8.ai account. The API key for system reporting at `https://api.tryxlr8.ai` is a different key. It will not connect you here.

Send the key with every request:

```http
Authorization: Bearer <your_api_key>
```

Keep the key somewhere private. The samples below use `$XLR8_API_KEY` as a placeholder. If your client saves that text instead of the key, paste the key itself. Some clients, including Claude Desktop on Windows, send an empty header when they leave the placeholder as-is, and sign-in fails.

If the key is for your account and not one organization, ask the assistant which organizations you can use, then pick one.

<AccordionGroup>
  <Accordion title="Cursor">
    Add the key to the same `mcp.json` file:

    ```json
    {
      "mcpServers": {
        "xlr8": {
          "url": "https://mcp.tryxlr8.ai/mcp",
          "headers": {
            "Authorization": "Bearer $XLR8_API_KEY"
          }
        }
      }
    }
    ```
  </Accordion>

  <Accordion title="Claude Code">
    ```bash
    claude mcp add --transport http xlr8 https://mcp.tryxlr8.ai/mcp \
      --header "Authorization: Bearer $XLR8_API_KEY"
    ```
  </Accordion>

  <Accordion title="VS Code">
    ```json
    {
      "servers": {
        "xlr8": {
          "type": "http",
          "url": "https://mcp.tryxlr8.ai/mcp",
          "headers": {
            "Authorization": "Bearer $XLR8_API_KEY"
          }
        }
      }
    }
    ```
  </Accordion>

  <Accordion title="Codex">
    Point Codex at the variable name so the key stays out of the file:

    ```bash
    codex mcp add xlr8 --url https://mcp.tryxlr8.ai/mcp --bearer-token-env-var XLR8_API_KEY
    ```

    ```toml
    [mcp_servers.xlr8]
    url = "https://mcp.tryxlr8.ai/mcp"
    bearer_token_env_var = "XLR8_API_KEY"
    ```
  </Accordion>

  <Accordion title="Another client">
    ```json
    {
      "mcpServers": {
        "xlr8": {
          "type": "http",
          "url": "https://mcp.tryxlr8.ai/mcp",
          "headers": {
            "Authorization": "Bearer $XLR8_API_KEY"
          }
        }
      }
    }
    ```

    For a client that can only run a local program, add `"--header"` and `"Authorization: Bearer $XLR8_API_KEY"` after the URL in the `mcp-remote` configuration above.
  </Accordion>
</AccordionGroup>

## Check the connection

Ask the assistant to list your XLR8.ai organizations. You should see each organization on your account, with its name and your role.

You only see organizations you belong to. Tell the assistant which organization to use before you ask it to do anything else.

The assistant starts with a few tools and looks up the rest as you ask. A short list means the connection worked.

## Troubleshooting

<AccordionGroup>
  <Accordion title="I opened the URL in a browser">
    Opening `https://mcp.tryxlr8.ai/mcp` in a browser does not load a page. Paste that URL into your AI client and sign in there.
  </Accordion>

  <Accordion title="Sign-in never finishes">
    Remove the server or connector and add it again. Then sign in with the same account you use at [app.tryxlr8.ai](https://app.tryxlr8.ai).
  </Accordion>

  <Accordion title="The client says Unauthorized">
    The saved sign-in is missing or wrong. Remove the server and connect again so you can sign in from scratch.

    If you are using an API key, paste it again with no extra spaces. The reporting key for `https://api.tryxlr8.ai` will not work here. If the header still contains `$XLR8_API_KEY`, the client did not fill in your key.
  </Accordion>

  <Accordion title="I cannot use an organization">
    Ask the assistant to list your organizations and choose one of those. It can only work in organizations your account belongs to.
  </Accordion>

  <Accordion title="I changed the config and nothing happened">
    Quit the client completely and open it again. Reloading the window often keeps the old connection.
  </Accordion>
</AccordionGroup>
