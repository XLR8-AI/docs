This guide walks you through creating and running your first experiment on XLR8.ai.

<Steps>
  <Step title="Sign in and set up your organization">
    Go to [app.tryxlr8.ai](https://app.tryxlr8.ai) and sign in. If you're new, create an account and set up your organization.

    Accept the Terms of Service when prompted, then use the organization switcher in the header to select or create your organization.

    Open **Settings** and save your **Company Name** and **Company Domain**. XLR8.ai pre-fills these across experiments, content tools, and social listening.
  </Step>
  <Step title="Create a query set">
    From the sidebar under **Strategy**, click **Query Generation**, then **New query set**.

    Enter your company name and website, choose **Visibility Analysis** or **Sentiment Analysis** and a subtype, then click **Analyze domain**. Review the suggested categories, optionally set **Queries per category**, click **Continue** to generate queries, edit them if needed, and **Save query set**.

    See [Query Generation](/query-generation) for CSV import, Keyword Planner, and comments.
  </Step>
  <Step title="Create your first experiment">
    From the sidebar under **Strategy**, click **Experiments**, then **New Experiment**.

    Creating an experiment has two steps:

    1. **Query set** — pick the saved set (type, company, domain, and aliases come from it)
    2. **Create** — select AI models and optionally set a location

    Click **Create Experiment** to save the configuration and start the first run.
  </Step>
  <Step title="Wait for the execution to finish">
    On the experiment detail page, the execution status updates as it progresses. When it completes, open the results tabs to review the run.

    For visibility experiments, start with **Overview**, then dig into **Query Analytics** and **Source Analytics**. For sentiment experiments, use **Overview** and **Detailed Analysis**.
  </Step>
  <Step title="Explore insights and next actions">
    Use these follow-on tools with your first experiment:

    - **Insights** — ask natural language questions about the experiment data
    - **Analytics** — compare multiple executions over time once you have more than one run
    - **Action Center** — sync and track recommended fixes from sentiment results
  </Step>
</Steps>
